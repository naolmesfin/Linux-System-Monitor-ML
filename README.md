# Linux System Performance Monitor 🐧📈

This project demonstrates a cross-platform data pipeline that monitors Linux system resources during heavy computational tasks.

## How it Works
1. **Collector:** A Bash script (`monitor.sh`) runs in an Ubuntu environment, logging CPU and RAM usage to a CSV.
2. **Analysis:** A Jupyter Notebook uses **Pandas** and **Matplotlib** to analyze the logs and visualize performance spikes.

## Tools Used
* **OS:** Ubuntu (Linux)
* **Scripting:** Bash
* **Data Science:** Python, Pandas, Matplotlib
